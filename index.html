\[ w_0 = 3 \]

2. Démontrer par récurrence que, pour tout entier naturel \(n\), \(2 \leq u_n \leq u_{n+1} \leq 6,5\). / Montrer par récurrence que pour tout entier naturel \(n\), \(1 \leq u_{n+1} \leq u_n\).

▼
1. Démontrer par récurrence que, pour tout entier naturel \(n\), \(2\leq u_n\leq u_{n+1}\leq 6,5\).
Données :
\[ u_0=2 \]
\[ u_{n+1}=\frac{u_n+6,5}{2} \]
Initialisation :
\[ u_0=2 \]
\[ u_1=\frac{2+6,5}{2}=4,25 \]
\[ 2\leq 2\leq 4,25\leq 6,5 \]
Hérédité :
\[ 2\leq u_n\leq u_{n+1}\leq 6,5 \]
\[ u_{n+2}=\frac{u_{n+1}+6,5}{2} \]
\[ u_{n+1}\leq 6,5 \]
\[ 2u_{n+1}\leq u_{n+1}+6,5 \]
\[ u_{n+1}\leq u_{n+2} \]
\[ u_{n+2}\leq 6,5 \]
\[ 2\leq u_{n+1}\leq u_{n+2}\leq 6,5 \]
Conclusion :
\[ \forall n\in\mathbb N,\quad 2\leq u_n\leq u_{n+1}\leq 6,5 \]
2. Montrer par récurrence que, pour tout entier naturel \(n\), \(1\leq u_{n+1}\leq u_n\).
Données :
\[ u_0=6 \]
\[ u_{n+1}=\frac{u_n+1}{2} \]
Initialisation :
\[ u_1=\frac{6+1}{2}=\frac72 \]
\[ 1\leq \frac72\leq 6 \]
Hérédité :
\[ 1\leq u_{n+1}\leq u_n \]
\[ u_{n+2}=\frac{u_{n+1}+1}{2} \]
\[ 1\leq u_{n+1} \]
\[ 2\leq u_{n+1}+1 \]
\[ 1\leq \frac{u_{n+1}+1}{2} \]
\[ u_{n+1}\leq u_n \]
\[ \frac{u_{n+1}+1}{2}\leq u_{n+1} \]
\[ u_{n+2}\leq u_{n+1} \]
\[ 1\leq u_{n+2}\leq u_{n+1} \]
Conclusion :
\[ \forall n\in\mathbb N,\quad 1\leq u_{n+1}\leq u_n \]

3. Démontrer par récurrence que, pour tout entier naturel \(n\), \(p_n = 0,125 \times 0,2^{n-1} + 0,875\). / Montrer que \(a_n \geq 3^n - 1\).

▼
3. Démontrer par récurrence que, pour tout entier naturel \(n\), \(p_n=0,125\times 0,2^{n-1}+0,875\)
Données :
\[ p_1=1 \]
\[ p_{n+1}=0,2p_n+0,7 \]

\[ p_1=0,125\times 0,2^{1-1}+0,875 \]
\[ =0,125\times1+0,875 \]
\[ =1 \]
Hérédité :
\[ p_n=0,125\times0,2^{n-1}+0,875 \]

\[ =0,025\times0,2^{n-1}+0,175+0,7 \]
\[ =0,125\times0,2^n+0,875 \]
\[ p_{n+1}=0,125\times0,2^{(n+1)-1}+0,875 \]
Conclusion :
\[ \forall n\in\mathbb N^*,\quad p_n=0,125\times0,2^{n-1}+0,875 \]

6. En déduire que, pour tout entier naturel \(n\), \(u_n = 20 + 10(1/2)^n\). / En déduire que \(\ln(2) = 2^n \ln(u_n)\).

▼
Partie 1. En déduire que, pour tout entier naturel \(n\), \(u_n=20+10\left(\frac12\right)^n\)
Données :
\[ v_n=u_n-20 \]
\[ v_n=10\left(\frac12\right)^n \]
Calcul :
\[ u_n-20=10\left(\frac12\right)^n \]
\[ u_n=20+10\left(\frac12\right)^n \]
\[ u_n=20+10\left(\frac12\right)^n \]
Partie 2. En déduire que \(\ln(2)=2^n\ln(u_n)\).
Données :
\[ u_n=2^{\frac{1}{2^n}} \]
Calcul :
\[ \ln(u_n)=\ln\left(2^{\frac{1}{2^n}}\right) \]
\[ \ln(u_n)=\frac{1}{2^n}\ln(2) \]
\[ 2^n\ln(u_n)=\ln(2) \]
\[ \ln(2)=2^n\ln(u_n) \]

7. En déduire que la suite \((u_n)\) est convergente.

▼
Données :
\[ u_n=20+10\left(\frac12\right)^n \]
\[ \lim_{n\to+\infty}\left(\frac12\right)^n=0 \]
Calcul :
\[ \lim_{n\to+\infty}u_n=\lim_{n\to+\infty}\left[20+10\left(\frac12\right)^n\right] \]
\[ =20+10\times0 \]
\[ =20 \]
\[ \lim_{n\to+\infty}u_n=20 \]
Conclusion :
\[ \text{La suite }(u_n)\text{ est convergente vers }20. \]

8. Déterminer / Calculer la limite de la suite \((u_n)\).

▼
Données :
\[ u_n = \frac{3n^2 + 2n - 1}{2n^2 - 5n + 4} \quad n \in \mathbb{N} \]
\[ \lim_{n \to +\infty} n = +\infty \]
Calcul :
\[ \lim_{n \to +\infty} u_n = \lim_{n \to +\infty} \frac{3n^2 + 2n - 1}{2n^2 - 5n + 4} \]
\[ = \lim_{n \to +\infty} \frac{3 + \frac{2}{n} - \frac{1}{n^2}}{2 - \frac{5}{n} + \frac{4}{n^2}} \]
\[ = \frac{3 + 0 - 0}{2 - 0 + 0} \]
\[ \lim_{n \to +\infty} u_n = \frac{3}{2} \]
